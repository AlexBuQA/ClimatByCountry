# Анализ климатических данных: временные ряды

Домашнее задание по модулю «Временные ряды»: базовый пайплайн прогнозирования
на реальных климатических данных — датасет
[Climate Change: Earth Surface Temperature Data](https://www.kaggle.com/datasets/berkeleyearth/climate-change-earth-surface-temperature-data)
(Berkeley Earth).

Анализ выполнен для **Беларуси**: среднемесячная температура с 1900 по 2013 год.

## Основной ноутбук (`climate_time_series_belarus.ipynb`)

Решение задания по файлу `GlobalLandTemperaturesByCountry.csv`:

1. **Подготовка данных** — загрузка, фильтрация по стране, приведение индекса
   к дате, проверка пропусков и частоты ряда, базовый график.
2. **Holdout-разбиение** — первые 80% наблюдений в обучение, последние 20% в тест,
   визуализация train/test на одном графике.
3. **Rolling window (backtesting)** — скользящее окно: обучающий отрезок 120 месяцев
   (10 лет), горизонт прогноза 12 месяцев, визуализация первых двух сплитов.
4. **Генерация признаков** — лаги `t-1` и `t-12`, номер месяца, индикатор зимы
   (декабрь–февраль).
5. **Модель** — линейная регрессия на лаговых и календарных признаках,
   прогноз на тестовой выборке.
6. **Метрики** — MAE, RMSE, MAPE с краткой интерпретацией.

### Результаты основного ноутбука

Линейная регрессия на лагах `t-1`, `t-12` и календарных признаках
(месяц, индикатор зимы) на тестовой выборке 1990–2013 гг.:

| Метрика | Значение |
|---|---|
| MAE | ≈ 2.2 °C |
| RMSE | ≈ 2.8 °C |
| MAPE | ≈ 65% (велик из-за околонулевых температур — ряд пересекает 0 °C) |

## Дополнительные ноутбуки

Разведочный анализ остальных файлов датасета
(не входят в обязательное задание):

- **`bonus_1_global_temperatures.ipynb`** — глобальная температура суши
  и «суша + океан» с 1750 года, оценка скорости потепления за разные периоды,
  сравнение тренда Беларуси с глобальным через аномалии относительно
  базового периода 1951–1980 гг. Вывод: Беларусь теплеет быстрее планеты
  (~+1.4 против ~+1.0 °C/100 лет за 1900–2013 гг.).
- **`bonus_2_major_cities.ipynb`** — скорость потепления 100 крупнейших городов
  мира с 1900 года, топ-10 лидеров (Мешхед, Харбин, Москва…), сравнение динамики
  городов Европы и мира, замечание про эффект «острова тепла».
- **`bonus_3_states.ipynb`** — средняя скорость потепления регионов по 7 странам
  (лидируют Россия и Канада), топ-10 регионов России по росту температуры
  (Оренбургская, Саратовская области, Тыва).

## Как запустить локально (VS Code)

1. Клонируйте репозиторий:

   ```bash
   git clone <url-вашего-репозитория>
   cd climate-time-series-belarus
   ```

2. Создайте виртуальное окружение и установите зависимости:

   ```bash
   python -m venv .venv
   source .venv/bin/activate        # Windows: .venv\Scripts\activate
   pip install -r requirements.txt
   ```

3. Откройте любой ноутбук из папки `notebooks/` в VS Code,
   выберите интерпретатор из `.venv` и выполните все ячейки (**Run All**).
   Полный прогон основного ноутбука занимает меньше минуты.

## Примечание по данным

Датасеты **включены в репозиторий** (все файлы меньше лимита GitHub в 100 МБ),
поэтому проект запускается сразу после клонирования — ничего скачивать
с Kaggle не нужно. Источник данных:
[Kaggle — Climate Change: Earth Surface Temperature Data](https://www.kaggle.com/datasets/berkeleyearth/climate-change-earth-surface-temperature-data)
(компиляция Berkeley Earth).

В исходных данных XVIII века (1740–1750-е гг.) много пропусков, поэтому в
основном ноутбуке анализ ведётся с 1900 года: с этого момента ряд по Беларуси
полный (1364 месячных наблюдения, единственный пропуск в последнем месяце удалён).
